Build inputs are obtained from their official upstream sources. This project does not redistribute OBS, FFmpeg, AMD drivers, or Zig binaries in its plugin/source release package.

| Component | Use | Upstream |
| --- | --- | --- |
| OBS Studio 33.0.0 | Headers and runtime API | https://github.com/obsproject/obs-studio/tree/33.0.0 |

OBS headers are GPL-2.0-or-later. FFmpeg headers retain their upstream notices; individual runtime build licenses depend on the OBS distribution. Static runtime portions linked by the Zig toolchain include LLVM/libc++/compiler-rt, MinGW-w64 and their applicable notices/exceptions, available in the pinned Zig source distribution. The plugin source license does not relicense those components.

Runtime notice texts are included under third-party and copied into dist by the build. Source archives provide the build recipe and exact dependency versions. Review changes to dependencies and licenses before a public release.

## Installer engine and translations

The EXE installer is generated by official Inno Setup 6.7.3 (Jordan Russell and Martijn Laan). Its public source and upstream translations are at https://github.com/jrsoftware/issrc/tree/is-6_7_3. The embedded installer engine retains its upstream copyright notices. See third-party/inno-setup-LICENSE.txt. installer/languages/ChineseSimplified.isl is the unmodified upstream translation from that tag; Japanese/Korean/default English messages come from the pinned compiler distribution. Project-specific installer messages and Pascal source are GPL-2.0-or-later. The compiler itself is a build tool, not bundled as a separate user application.

A [notice-to-component index](third-party/README.md) explains what each bundled notice file covers.
