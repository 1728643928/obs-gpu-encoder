# Third-party components and acknowledgements

GPU Encoder Bridge's project-authored source is GPL-2.0-or-later; see [LICENSE](LICENSE). Reused files and linked components retain their own upstream notices and terms.

The [project homepage](README.md#acknowledgements-and-sources) gives a visible summary. This document records the scope and exact source locations, distinguishing implementation references, runtime dependencies, directly reused files and README design guidance.

## Encoder dependencies and implementation references

| Component | Use | Upstream |
| --- | --- | --- |
| OBS Studio 33.0.0 | Encoder headers and host API; its AMF implementation was consulted during development. OBS owns rendering, audio and stream publishing. | [Tagged source](https://github.com/obsproject/obs-studio/tree/33.0.0) |
| FFmpeg n8.0 | Headers; dynamically links OBS-provided libavcodec 62 and libavutil 60 for AMF encoding and D3D11 hardware contexts. | [Tagged source](https://github.com/FFmpeg/FFmpeg/tree/n8.0) |
| AMD AMF runtime | Hardware encoding, supplied by the installed display driver and used through FFmpeg. AMD's official guide was a device-selection and validation reference. | [AMF](https://github.com/GPUOpen-LibrariesAndSDKs/AMF) · [FFmpeg/AMF guide](https://github.com/GPUOpen-LibrariesAndSDKs/AMF/wiki/FFmpeg%20and%20AMF%20HW%20Acceleration) |
| Zig 0.14.1 | Portable Clang/LLD, MinGW headers and statically linked C/C++ runtime components. | [Pinned toolchain](https://github.com/ziglang/zig/tree/0.14.1) |

Specific implementation/API reference points:

- OBS: [encoder interface](https://github.com/obsproject/obs-studio/blob/33.0.0/libobs/obs-encoder.h) and [AMF implementation](https://github.com/obsproject/obs-studio/blob/33.0.0/plugins/obs-ffmpeg/texture-amf.cpp). The corresponding integration in this repository is [src/plugin.cpp](src/plugin.cpp).
- FFmpeg: [AMF encoder implementation](https://github.com/FFmpeg/FFmpeg/blob/n8.0/libavcodec/amfenc.c) and [D3D11 context interface](https://github.com/FFmpeg/FFmpeg/blob/n8.0/libavutil/hwcontext_d3d11va.h). [src/backend.cpp](src/backend.cpp) calls these libraries and binds the selected D3D11 device. The upstream codec implementation remains in the OBS-provided FFmpeg DLLs; it is not vendored as this project's encoder source.
- AMD: the official guide's GPU-selection and hardware-encoding documentation informed the initial independent-device experiments and validation. The plugin reaches AMF through FFmpeg rather than shipping an AMD driver or standalone AMF SDK.

Build inputs are obtained from their official upstream sources. Plugin/source release packages do not redistribute OBS, FFmpeg, AMD drivers or Zig executables. The build recipe pins versions and download SHA-256 values in [scripts/build.mjs](scripts/build.mjs).

OBS headers are GPL-2.0-or-later. FFmpeg headers retain their upstream notices; individual runtime build licenses depend on the OBS distribution. Static runtime portions linked by the Zig toolchain include LLVM/libc++/compiler-rt, MinGW-w64 and their applicable notices/exceptions. The plugin source license does not relicense those components.

## Build and CI services

[Node.js](https://github.com/nodejs/node) runs the repository's build/documentation scripts. CI uses GitHub's official [checkout](https://github.com/actions/checkout), [setup-node](https://github.com/actions/setup-node), [upload-artifact](https://github.com/actions/upload-artifact) and [download-artifact](https://github.com/actions/download-artifact) actions. Their exact revisions are pinned in [.github/workflows/build.yml](.github/workflows/build.yml); these are build services, not bundled plugin features.

Runtime notice texts are included under [third-party/](third-party/README.md) and copied into distributions by the build. Source archives provide the build recipe and exact dependency versions. Retain original copyright/license notices and update this document and all four homepage summaries when reusing or adapting additional work.
